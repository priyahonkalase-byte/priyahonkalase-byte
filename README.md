I’m an Electronics & Computer Science undergrad operating purely on caffeine, loud playlists, and the stubborn belief that anything can be automated or soldered. Most days, you’ll find me frankensteining bare display panels out of dead tech, flashing MicroPython onto microcontrollers, or writing Python scripts and local LLM workflows just so I never have to click a manual button twice. When my laptop isn’t heating up the room from Blender renders or DaVinci Resolve timelines, I’m either obsessing over moody architecture in Roblox Studio or aggressively planning out my projects so everything gets time. I like my hardware tactile, my code functional, and my project builds just chaotic enough to stay interesting.
